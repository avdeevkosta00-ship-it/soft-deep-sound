# Soft&Deep Sound

Десктопный плеер.
Внутри: Sound Pitcher, Ambient Generator со Smart Duck, 10-полосный эквалайзер, гибридный поиск (медиатека + открытые источники), визуалайзер, живой фон, волновая полоса перемотки, 4 темы в одном стиле (Мягкая, Глубокая, Жемчуг, Обсидиан) с живыми анимированными формами на фоне, русский и английский интерфейс, свои обложки, перестраиваемые панели.

## Как получить готовую программу (.exe)

1. Дважды щёлкните **BUILD-EXE.bat**. Скрипт сам поставит Node.js, если его нет (через winget), скачает компоненты и соберёт программу.
2. Откроется папка `dist`:
   - `SoftDeepSound-Setup-1.9.0.exe` — установщик, создаёт ярлык на рабочем столе;
   - `SoftDeepSound-Portable-1.9.0.exe` — один файл, работает без установки.
3. Эти файлы можно отправлять друзьям: им ничего устанавливать и вводить не нужно.

Windows может показать «Система Windows защитила ваш компьютер», потому что у программы нет платной цифровой подписи. Нужно нажать **«Подробнее» → «Выполнить в любом случае»**.

**Вариант без сборки на своём ПК:** загрузите проект в репозиторий на GitHub. Файл `.github/workflows/build.yml` сам соберёт .exe на серверах GitHub: вкладка **Actions** → последний запуск → **Artifacts**.

**Для разработки:** `npm install`, затем `npm start`.

## Как пользоваться

| Действие | Как |
|---|---|
| Добавить музыку | «Добавить музыку» / «или выбрать папку», либо перетащить файлы и папки в окно |
| Положить в плейлист | после импорта — чипсы в уведомлении; или ПКМ → «Добавить в плейлист»; или перетащить трек на плейлист слева |
| Новый плейлист | «+» у раздела «Плейлисты» (двойной клик по плейлисту — переименовать) |
| Доп. функции | кнопка ≡ рядом с транспортом → Pitch / Ambient Generator / Equalizer |
| Обложка | клик по большой обложке, ПКМ по треку или плейлисту → «Сменить обложку…» |
| Панели | полоска сверху панели — перетащить на другое место; край между панелями — ширина; кнопка ▥ в шапке — показать/скрыть/сбросить |
| Тема | кнопка с кружком в шапке |
| Язык | Настройки → Язык (по умолчанию — язык Windows) |
| SoundCloud | в результатах поиска — «Открыть на SoundCloud» (поиск откроется в браузере) |
| Погружение (полный экран) | двойной клик по панели «Сейчас играет» или клавиша F; выход — Esc, кнопка ↙ или двойной клик по обложке |
| Похожие треки | ПКМ по треку → «Похожие треки» (подбор по темпу, тональности, энергии и звучанию) |
| Умная сессия | пункт «Умная сессия» слева: настроение, длительность, темп → готовая очередь или плейлист |
| Состояние медиатеки | пункт слева: битые названия (кракозябры), дубликаты, нет обложки/тегов, пропавшие файлы, качество |
| Изменить данные трека | ПКМ по треку → «Изменить данные…» (меняется только в плеере, сами файлы не трогаются) |
| Сохранить с эффектами | настройте Pitch / Эквалайзер / Ambient → кнопка «Сохранить с эффектами» в панели инструментов, ПКМ по треку или Ctrl+S. MP3 320 kbps или WAV, новая версия сразу появляется в медиатеке; оригинал не меняется |
| Soft ↔ Deep | переключатель SOFT / DEEP в шапке или клавиша D |
| Визуализация на весь экран | клик по волне в панели «Сейчас играет» или клавиша V |
| Работа в фоне | крестик сворачивает плеер в трей (значок возле часов), музыка продолжает играть. Клик по значку — открыть, правая кнопка — играть/пауза, следующий, предыдущий, громкость, выйти. Отключается в Настройках |
| Таймер сна | правая кнопка по значку в трее → «Таймер сна»: через 15–90 минут или в конце трека, музыка плавно затихает |
| Автозапуск | Настройки или меню трея → «Запускать вместе с Windows» (плеер тихо стартует в трее) |
| Управление с панели задач | наведите на значок на панели задач — кнопки ⏮ ⏯ ⏭; работают и мультимедийные клавиши клавиатуры |
| На главную | клик по логотипу |
| Поиск | Ctrl+K. Enter — сразу включить лучший трек из медиатеки, Shift+Enter — все результаты и поиск в сети. Понимает опечатки, транслит и неправильную раскладку |
| Трек с любого сайта | вставьте ссылку на страницу или файл прямо в поиск (или в карточку внизу результатов) → плеер найдёт на странице все аудиофайлы |

**Горячие клавиши:** Space — пуск/пауза · ←/→ — ±5 с (Shift — ±15 с) · Ctrl+←/→ — трек · ↑/↓ — громкость · M — без звука · S — перемешать · R — повтор · P / A / E — Pitch / Ambient / Equalizer · Esc — закрыть панель.

Ручки и фейдеры: тянуть мышью, крутить колесом, двойной клик — сброс.

## Структура

```
main.js                  окно, протокол sds://, IPC, теги/обложки
preload.js               узкий мост в renderer
src/search/providers.js  источники веб-поиска (Openverse, Internet Archive, Jamendo)
src/search/downloader.js безопасное скачивание
renderer/
  index.html, styles.css дизайн-система (Soft/Deep)
  js/app.js              медиатека, плейлисты, очередь, поиск, представления
  js/audio-engine.js     Web Audio граф
  js/pitch-worklet.js    сдвиг тональности (AudioWorklet)
  js/ambient.js          процедурные эмбиенты + Smart Duck
  js/bpm-worker.js       BPM + пики волны (Web Worker)
  js/visualizer.js       визуалайзер «стеклянная лента» и волновая перемотка
  js/tools.js            стойка плагинов
  js/splash.js           приветственная анимация
```

Данные: `%APPDATA%/Soft&Deep Sound/library.json`. Скачанное: `Музыка/Soft&Deep Sound`.

Подробности решений и ответы по гибридному поиску — в **ARCHITECTURE.md**.


MP3-кодирование — библиотека [lamejs](https://github.com/zhuker/lamejs) (LGPL-3.0), файл `renderer/vendor/lame.min.js`.

Шрифт Unbounded — SIL Open Font License (`renderer/fonts/unbounded-OFL.txt`).
